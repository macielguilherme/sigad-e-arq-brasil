# 🗂️ SIGAD - e-ARQ Brasil v2

Sistema Informatizado de Gestão Arquivística de Documentos baseado no Modelo de Requisitos e-ARQ Brasil v2.

## 📋 Funcionalidades Implementadas

### ✅ Capítulo 1.1 - Plano de Classificação
- Criação de classes com hierarquia
- Edição e exclusão de classes
- Histórico de alterações (1.1.5)
- Gerenciamento de metadados (1.1.10)
- Exportação/Importação (1.1.16)
- Relatórios de gestão (1.1.17)
- Busca avançada (1.1.18)

### ✅ Capítulo 1.2 - Temporalidade
- Configuração de prazos de guarda
- Controle de eventos de contagem
- Histórico de alterações (1.2.8)
- Exportação/Importação (1.2.9)
- Verificação de prazos vencidos

### ✅ Capítulo 1.3 - Documentos
- Criação e classificação de documentos
- Reclassificação com histórico (1.3.9, 1.3.10, 1.3.11)
- Referências cruzadas (1.3.12)

### ✅ Capítulo 2.1 - Captura
- Captura individual de documentos
- Componentes digitais (2.1.3)
- Metadados completos (2.1.4)
- Controle de versões (2.1.16)
- Tesauro (2.1.10)
- Sugestão automática de classes (2.1.17)
- Fluxo de captura distribuído (2.1.18)

### ✅ Capítulo 2.2 - Captura em Lote
- Importação em lote via JSON
- Validação prévia

### ✅ Capítulo 2.3 - Captura de E-mail
- Captura de mensagens eletrônicas
- Anexos
- Relacionamento com documentos

## 🚀 Tecnologias

- **Backend**: Node.js + Express + SQLite
- **Frontend**: HTML + CSS + JavaScript Vanilla
- **Banco de Dados**: SQLite3
